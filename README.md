## Deploy

`wrangler deploy` needs `web/dist`. Dashboard **Build command** cannot stay `None`.

| Field | Value |
| --- | --- |
| Root directory | `/web` |
| Branch | `main` |
| Build command | `npm install && npm run build` |
| Deploy command | `npx wrangler deploy` |

`web/wrangler.jsonc` also has `build.command` so deploy builds even if the dashboard field is empty.
